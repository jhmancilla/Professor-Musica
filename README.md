# ProfeMusic - Instalação Local

Este projeto ajuda professores de espanhol a criar exercícios de completar lacunas com músicas.

## Como rodar

1. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
2. Baixe todos os arquivos do projeto para uma pasta.
3. Renomeie o arquivo `.env.example` para `.env` e coloque sua Chave de API do Google Gemini.
4. Abra o terminal na pasta do projeto e execute:

```bash
# Instala as dependências
npm install

# Roda o servidor local
npm run dev
```

5. Abra o link que aparecerá no terminal (ex: http://localhost:5173).
